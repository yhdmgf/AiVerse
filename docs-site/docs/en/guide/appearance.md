# Appearance and Language

On the "Settings" page, tap "Appearance" to enter the appearance settings page, which is grouped into General (theme, chat bubbles, background image), Font (chat / input box font size, code font size, UI scale), Interface density, Corner radius, Code display, input box quick bar, new conversation entries, and so on. Changes take effect immediately and are remembered; tapping "Language" pops up the language selection window. The whole set of appearance settings can be exported / imported as a "Theme Pack" for one-tap restyling.

## Appearance Theme

The panel that pops up from "Appearance → Theme" has four sections: light/dark mode, color scheme, Material You color extraction, and colored icons. Choosing doesn't automatically close the panel, making it easy to compare several color schemes in a row.

### Light/Dark Mode

Three choices: follow system, fixed dark, fixed light.

### Color Scheme

Six presets, each with light and dark modes configured:

-   **HyperOS (default)**: the default color scheme, picking colors in the HyperOS style.
-   **HyperOS Glass** (**since 1.0.3**): keeps the HyperOS colors but makes surfaces like cards and pop-up layers a semi-transparent frosted glass texture; on Android 12+, standalone pop-up layers add real background blur for a richer look.
-   **Blue**: blue tones.
-   **Coffee**: warm terracotta + an off-white paper-feel base.
-   **Graphite**: neutral cool gray with the least color interference.
-   **Forest**: low-saturation green.

The outer ring of a color swatch is that theme's page background and the inner ring is the primary color; the preview follows the current light/dark mode.

Git swimlane colors, log level colors, and the red/green of diff additions/deletions are functional indicators and don't change with the theme, avoiding the same meaning having inconsistent colors across themes. The code editor's syntax highlighting and the terminal color scheme are separate settings of their own.

### Material You Color Extraction

When enabled, colors are extracted from the system wallpaper and the color scheme selected above no longer applies (the swatches turn gray). Off by default.

Requires Android 12 or above; on lower versions the switch is unavailable and the description says so directly. The wallpaper palette is generated by the system, and results vary a lot between phone manufacturers; if you're unhappy with the effect, just turn it off.

### Colored Icons

Settings page icons pick their color by icon name by default (each icon type has a fixed color that doesn't drift with theme presets); when turned off, icons become a uniform gray-white.

## Chat Bubble Style

"Appearance → Chat bubbles" sets the bubble style for **user messages** and **AI replies** separately (**since 1.0.0** they're split into independent configs that don't affect each other). The selection screen shows the send and receive sides side by side for easy comparison. Both sides include: Classic white outline, Soft shadow, Minimal pure white, Dark night, Comic, Fresh green, Heartfelt moment, and Original; **the AI reply side additionally has "No bubble"** (**since 1.0.0**, which removes the bubble container so AI replies are laid directly on the page). Choosing either side takes effect immediately and is remembered; the default is Classic white outline.

**Bubble transparency** (**since 1.0.3**): user bubbles and AI bubbles each have their own slider, adjustable from 10% to 100%, defaulting to 100% (fully opaque). While dragging, a preview stays below, rendering live according to the currently selected style and transparency, and only commits on release. Bubble transparency is exported / imported together with the theme pack.

## Input Box Quick Bar

"Appearance → Input box quick bar" controls showing and hiding each button on the quick bar above the input box (**Mode switch is always kept** and isn't in this list). The button order matches the settings page:

-   **Switch model quick button**
-   **Thinking intensity quick button**
-   **Web search toggle**
-   **Switch folder quick button**
-   **MCP quick button**
-   **Optimize input quick button** (**since 1.0.3**, see below)
-   **Plus quick button** (**since 1.0.3**, the attachment upload entry)

**By default only three are enabled — switch folder, switch model, and thinking intensity**; MCP, web search, optimize input, and plus are off by default and can be enabled yourself. Changes sync to the chat page immediately.

A single tap on the "Optimize input" button hands the content already written in the input box to the model to polish and fills it back (tapping does nothing when the input box is empty); long-pressing the button enters the "Optimize input dedicated model" setting (following the current chat model by default), see [Default Models](https://aivapp.cn/md/guide/default-models.md).

-   **Sort by usage frequency** (**since 1.0.0**): enabled buttons are arranged from most to least frequently used, so commonly used buttons come first.
-   **Overflow containment** (**since 1.0.0**): buttons that don't fit are tucked into the "···" menu on the right; tap to expand and view.
-   **Usage ring shows percentage** (**since 1.0.0**): the center of the context usage ring directly shows the percentage in use.

## Interface Density

"Appearance → Interface density" switches between three levels (**since 1.0.3**), controlling the scaling of overall spacing, corner radius, and component heights (it doesn't affect font size, which has its own independent slider):

-   **Compact**: scale 0.85, more content per screen.
-   **Standard** (default): scale 1.0, exactly matching the look of the old version.
-   **Comfortable**: scale 1.2, larger and looser spacing.

The density level applies to core areas like the input box, bottom tabs, list rows, and Markdown body, and changes take effect immediately.

## Corner Radius

"Appearance → Corner radius" (**since 1.0.3**) adjusts the size of five types of corner radius separately, with live preview while dragging and saving on release, plus a one-tap restore to defaults:

-   **Card corner radius**: default 12dp
-   **Button corner radius**: default 10dp
-   **Input box corner radius**: default 12dp
-   **Bubble corner radius**: default 10dp
-   **Image corner radius**: default 12dp

Corner radius is exported / imported together with the theme pack.

## Code Display

"Appearance → Code display" (**since 1.0.3**) controls how code blocks appear in chat:

-   **Code block font size**: a font size slider that independently controls the code block font size (independent of the chat bubble font size).
-   **Word wrap**: when enabled, long lines don't scroll horizontally and wrap automatically.
-   **Auto-collapse code blocks**: when enabled, overly long code blocks collapse automatically; tap "Expand all" to expand.
-   **Show line numbers**: when enabled, line numbers appear on the left of code blocks.

The code font size and the three toggles are all exported / imported with the theme pack.

## New Conversation Entries

When you start a new blank conversation, a row of clickable **quick entry cards** appears below the welcome message (**since 1.0.3**), for example to open the terminal, view Git changes, or fill a frequently used prompt into the input box in one tap. Four entries are preset by default: Open terminal, View Git changes, Write code for me, and Troubleshoot errors. Each card has the same height and wraps its icon in a rounded tray with a faint brand-colored backing (**since 1.0.5**), with the title and the subtitle each on one line.

In "Appearance → New conversation entries" you can add, remove, reorder, enable/disable, and customize icons, **up to 6**:

-   Three actions are supported: open terminal, open Git, and fill a prompt into the input box.
-   Icons support vector icons, text, or images.
-   Deleting a single entry and restoring presets both require a second confirmation; restoring presets rebuilds the default four entries and removes any added or modified entries.

## Custom Background Image

You can set a global background image:

-   **Choose image**: pick one from the system gallery as the app's global background, layered over the content on all pages (watermark effect, doesn't intercept touches). The terminal page keeps a pure black background and doesn't show the background.
-   **Display mode** (**since 1.0.3**): fill and crop (default, crops edges to fill the screen), show fully (the whole image is visible, may leave margins), and bottom artwork (the image sticks to the bottom while the top content area stays clean).
-   **Artwork height** (only effective for "Bottom artwork", **since 1.0.3**): the proportion of the screen the artwork occupies, from 20% to 80%, default 45%.
-   **Mask strength**: the slider shows 0% to 100%, with the actual effective range mapped to 0% to 85% (i.e. sliding to 100% equals 85% opacity) to keep text always readable. Default 35%, taking effect live while dragging.
-   **Remove background**: restores the default solid-color background.

The background image file is saved in the app's private directory, is **not exported with backups**, and needs to be set again when you switch devices.

## Theme Pack

"Appearance → Theme pack" (**since 1.0.3**) bundles the whole set of appearance settings for export, or imports from a file to apply in one tap:

-   **Export theme pack**: bundles the current appearance settings as JSON to share or back up.
-   **Import theme pack**: reads JSON from a file and applies it in one tap; if applying fails it shows "The theme pack may be invalid".

It covers light/dark mode, color scheme, Material You color extraction, colored icons, both sides' bubble styles, the four-level font size, interface density, code display, and both sides' bubble transparency; it **does not include the custom background image** (the background image goes through backup separately).

## Language

You can follow the system language or directly specify one of the supported languages.

## Terminal Appearance

The terminal's color theme, font, font size, and cursor style are a separate set of settings; see [Terminal](https://aivapp.cn/md/guide/terminal.md#appearance-settings).

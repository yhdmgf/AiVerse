# 角色系统

角色是一套可复用的「AI 人设」：每个角色包含名称、头像，以及影响 AI 行为与语气的设定（提示词片段）。会话开始时，系统会把所选角色的设定注入系统提示词，让 AI 按这个人设来回答。

应用内置了若干预设角色，开箱即用；你也可以创建自定义角色，随时为会话切换。

::: tip 角色设定影响 AI
所选角色的设定会在会话开始时注入系统提示词，直接影响 AI 的语气与行为。
:::

## 切换会话角色

聊天顶栏会显示当前会话使用的角色。点它弹出角色选择抽屉，列出所有可用角色（含头像与名称），选中即把该角色绑定到**当前会话**。

- **默认角色**：选择「默认角色」即不绑定特定角色，AI 按默认方式回答。
- **绑定当前会话**：切换角色只影响当前会话，不会改动其它会话。
- 角色头像会显示在顶栏、角色选择抽屉、聊天输入区等位置。

## 新建会话沿用上次角色

切换过角色后，新建的会话会沿用上一次选的角色，不必每次重切（**1.0.3 起**）。

已有的老会话各自保持原角色不变，不受影响。

## 角色与工作区绑定

在角色编辑页可以为一个角色指定「绑定工作区」。绑定后，选中该角色新建的会话会自动归入对应工作区，实现“切角色即切环境”的隔离体验（类似 qwenpaw 的工作区机制）。

- **不绑定**：默认行为，新建会话跟随当前选中的工作区。
- **绑定工作区**：选中该角色新建会话时，会话自动创建在该角色绑定的工作区内，会话管理页的分桶、筛选能力自动生效。
- **兼容性**：旧版本数据（workspaceId 为 null）完全兼容，行为不变；备份导出与导入均保留该字段。

## 管理角色

进入「设置 → 角色」，可以管理所有角色。内置预设角色与自定义角色一并管理。

- **新建**：点右上角的「＋」，填写名称、从相册选择头像、设定提示词内容。
- **编辑**：点某个角色进入详情，再点编辑，可修改名称、头像与设定内容。
- **名称长度**：名称有长度限制，超长会提示。
- **启用 / 停用**：可停用不需要的自定义角色，停用后不再出现在可切换列表里；内置预设角色不可停用，其身份正文始终注入。若不想要某个内置角色的默认身份，可在编辑页清空其身份正文。
- **删除**：可删除自定义角色。

## 角色与备份

角色会随「备份与还原」一起导出与导入。还原备份后，角色及其与会话的绑定关系一并恢复。

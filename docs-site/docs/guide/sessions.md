# 会话管理

「设置 → 数据与诊断 → 会话管理」把设备上所有工作区的聊天会话集中到一个页面，方便搜索历史、批量整理和导出单个会话。这里的操作直接改动聊天记录，删除前会二次确认。

## 入口位置

打开「设置 → 数据与诊断」，在「备份与还原」下方就是「会话管理」。进入后默认展示全部工作区的会话列表，点某个会话进入它的详情页。

## 按工作区分组

会话按所属工作区分成一组一组，每组标题显示工作区名称、来源标签（内置 / 外部 / 远程 / 离线）和会话数。分组标题可以点开或收起。当前正在使用的工作区排在最前面，之后依次是其它可用工作区，最后是不属于任何已知工作区的离线会话（例如已删除或已移动目录的工作区留下的历史记录）。

每个会话卡片显示标题、消息条数、更新时间和置顶标记。列表支持下拉刷新数据，左滑单个会话可直接删除。

## 筛选与搜索

列表顶部有一个搜索框和一排作用域切换标签：

- **全部**：显示所有工作区的会话。
- **当前环境**：只显示当前在线工作区（含内置、外部本地、远程）里的会话。
- **远程·离线**：只显示远程会话，以及工作区已不可用的离线会话。

搜索框会同时匹配两层内容：

- **按标题**：过滤上方分组里的会话卡片，只留标题命中的。
- **按消息正文**：关键词命中的消息会单独列在「消息内容命中」区域，显示所属会话标题和命中片段。点一条命中结果，直接打开那条消息所在的会话详情页，方便在长历史里快速定位某段对话。

搜索输入有轻微防抖，停顿一下才检索，避免每敲一个字都全库扫描。

## 批量操作

点右上角进入多选模式，可以勾选多个会话一起处理：

- **全选**：一键选中当前可见的全部会话，再点一次取消全选。
- **批量移动**：把选中的会话移到另一个工作区。目标工作区可以是任意分组，跨工作区移动会保留会话内容。如果目标是离线、远程或与来源不同的环境，会先弹出「跨环境移动会话」确认框，说明目标路径，确认后才执行——因为这类移动会改变会话绑定的运行环境。
- **批量删除**：删除选中的全部会话，弹窗会列出数量，确认后不可恢复。删除会话时，它的子会话、消息和代码检查点会一并清理。

会话正在运行时不可删除，对应的删除入口会置灰。

## 单个会话操作

在列表里长按某个会话，弹出操作菜单：

- **查看内容**：进入该会话的详情页。
- **在聊天中打开**：回到聊天界面并载入这个会话，接着聊。
- **移动到工作区**：单独移动这一个会话，流程与批量移动一致。
- **置顶 / 取消置顶**：置顶的会话在分组内排在最前。
- **重命名**：修改会话标题，留空不可保存。
- **导出**：把整个会话导出成一个压缩包，文件名形如 `aiverse-session-<标题>-<时间戳>.tar.gz`，通过系统文件选择器保存到你指定的位置。
- **进入多选**：进入批量模式并选中该会话。
- **删除**：删除这一个会话，需二次确认。

在会话卡片上单击，效果与「查看内容」相同。

## 会话详情

详情页顶部是一张信息卡：会话标题、来源标签、所属工作区路径，以及一条元信息（消息数 · 更新时间 · 使用的模型 · 是否运行中）。下面一行操作按钮横向排列：在聊天中打开、移动、重命名、导出、删除。

再往下是完整的消息列表，按角色（用户 / 助手 / 工具）区分底色，每条消息显示时间，右侧有复制按钮：

- **用户消息**：显示正文。
- **助手消息**：正文之外，如果有思考过程，会有一行「展开 / 收起思考过程」的开关，默认收起。
- **工具消息**：以等宽字体显示执行的指令和返回内容，过长时折叠。

如果这个会话派生过子会话（子代理），它们会一并列在详情里。

工作区当前不可用时，详情页可以正常浏览，但顶部会提示处于只读状态；此时仍能导出，移动和删除等改动类操作按实际情况处理。

::: tip 只想清掉调用记录
如果目的是减小聊天记录占用的空间，不用删整个会话，可以去「Token 统计」页右上角重置调用记录。
:::

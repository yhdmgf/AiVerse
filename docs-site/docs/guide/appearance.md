# 外观与语言

「设置」页点「外观」进入外观设置页，分通用（主题、聊天气泡、背景图）、字体（聊天/输入框字号、代码字号、界面缩放）、界面密度、圆角、代码显示、输入框快捷栏、新对话入口等组，改动即时生效并记住；点「语言」弹出语言选择窗口。整套外观设置可导出/导入「主题包」一键换装。

## 外观主题

点「外观 → 主题」弹出的面板里分四块：明暗模式、配色方案、莫奈取色、彩色图标。选择后不会自动关窗，便于连续对比多套配色。

### 明暗模式

三选一：跟随系统、固定深色、固定浅色。

### 配色方案

六套预设，深浅两种模式各自配好：

- **HyperOS（默认）**：默认配色，跟随 HyperOS 风格取色。
- **HyperOS 玻璃**（**1.0.3 起**）：沿用 HyperOS 配色，但把卡片、弹层等表面做成半透明磨砂玻璃质感，在 Android 12+ 的独立弹层会叠加真实背景模糊增强观感。
- **蓝色**：蓝色调。
- **咖啡**：暖赤陶色 + 米白纸感底。
- **石墨**：中性冷灰，颜色干扰最小。
- **森林**：低饱和绿。

色块外圈是该主题的页面底色、内圈是主色，预览会跟随当前明暗模式变化。

Git 泳道色、日志级别色、diff 增删的红绿属于功能标识，不随主题变化，避免同一含义在不同主题下颜色不一致。代码编辑器的语法高亮与终端配色也是各自独立的设置。

### 莫奈取色

开启后从系统壁纸提取配色，上方所选的配色方案不再生效（色块变灰）。默认关闭。

需要 Android 12 及以上系统；低版本设备上开关不可用，描述会直接提示。壁纸调色板由系统生成，不同手机厂商的取色结果差异较大，效果不满意关闭即可。

### 彩色图标

设置页图标默认按图标名取色（每类图标固定一种颜色，不随主题预设漂移）；关闭后图标统一为灰白色。

## 聊天气泡样式

「外观 → 聊天气泡」分别设置**用户消息**与 **AI 回复**两侧的气泡样式（**1.0.0 起**拆分为独立配置，互不影响），选择界面把收发两侧并排展示，方便对齐预览。两侧均含：经典白描边、柔和投影、极简纯白、暗夜模式、漫画风格、清新绿、心动时刻、原版；**AI 回复一侧另有「无气泡」**（**1.0.0 起**，去掉气泡容器，AI 回复直接铺在页面上）。选择任一侧样式即时生效并记住，默认经典白描边。

**气泡透明度**（**1.0.3 起**）：用户气泡与 AI 气泡各有独立滑块，可调 10% 到 100%，默认 100%（完全不透明）。拖动时下方常驻一块预览，按当前所选样式与透明度实时呈现，松手才落盘。气泡透明度会随主题包一起导出/导入。

**聊天面板透明系数**：顶栏、输入框、底部蒙版与悬浮面板共用这一系数，可调 10% 到 100%，默认 100%。100% 时与调整前完全一致；调低后它们按各自原有比例一起变透，透出背景图，文字与描边保持清晰。权限确认、计划审批、追问与目标面板保留 35% 的可读性下限。该设置与气泡透明度独立，并随备份导出/导入。

## 输入框快捷栏

「外观 → 输入框快捷栏」控制输入框上方快捷栏各按钮的显示与隐藏（**模式切换为必留项**，不在此列），按钮顺序与设置页一致：

- **切换模型快捷按钮**
- **思考强度快捷按钮**
- **联网搜索开关**
- **切换文件夹快捷按钮**
- **MCP 快捷按钮**
- **优化输入快捷按钮**（**1.0.3 起**，见下）
- **加号快捷按钮**（**1.0.3 起**，上传附件入口）

**默认仅开启切换文件夹、切换模型、思考强度三项**，MCP、联网搜索、优化输入、加号默认关闭，自行开启即可。改动即时同步到聊天页。

「优化输入」按钮单击把输入框里已写的内容交给模型润色后回填（输入框为空时点击无反应）；长按该按钮可进入「优化输入专用模型」设置（默认跟随当前聊天模型），见[默认模型](https://aivapp.cn/md/guide/default-models.md)。

- **按使用频率排序**（**1.0.0 起**）：开启的按钮按使用频率从高到低排列，常用按钮更靠前。
- **溢出收纳**（**1.0.0 起**）：放不下的按钮收进右侧「···」菜单，点击展开查看。
- **两行结构**（**1.0.5 起**）：第一行是输入框，第二行是工具条——当前模式只显示名称（点按向上弹出模式菜单选择，自动/构建/计划/专家四选一），名字后面跟一根细竖线，再往右是模型、工作区、MCP、思考等快捷入口。
- **发送键颜色**（**1.0.5 起**）：可发送状态统一用品牌主色；运行中为红色（停止）、消息排队为橙色；自动模式下模式名仍为红色，那是安全提示语义。

## 界面密度

「外观 → 界面密度」三档切换（**1.0.3 起**），控制整体间距、圆角与组件高度的缩放（不影响字号，字号另有独立滑块）：

- **紧凑**：缩放 0.85，同屏内容更多。
- **标准**（默认）：缩放 1.0，与旧版观感完全一致。
- **舒适**：缩放 1.2，间距更大、更宽松。

密度档会作用到输入框、底部 Tab、列表行、Markdown 正文等核心区域，改动即时生效。

## 圆角

「外观 → 圆角」（**1.0.3 起**）可分别调节五类圆角大小，拖动实时预览、松手保存，并提供一键恢复默认：

- **卡片圆角**：默认 12dp
- **按钮圆角**：默认 10dp
- **输入框圆角**：默认 12dp
- **气泡圆角**：默认 10dp
- **图片圆角**：默认 12dp

圆角会随主题包一起导出/导入。

## 代码显示

「外观 → 代码显示」（**1.0.3 起**）控制聊天里代码块的呈现：

- **代码块字体大小**：字号滑块，单独控制代码块字号（与聊天气泡字号独立）。
- **自动换行**：开启后长行不横向滚动，自动折行。
- **代码块自动折叠**：开启后超长代码块自动折叠，点击「展开全部」展开。
- **显示行号**：开启后代码块左侧显示行号。

代码字号与三项开关均随主题包导出/导入。

## 新对话入口

新建空白对话时，欢迎语下方会显示一排可点击的**快捷入口卡片**（**1.0.3 起**），例如打开终端、查看 Git 改动，或把一段常用提示词一键填入输入框。默认预置四个入口：打开终端、查看 Git 改动、帮我写代码、排查报错。每张卡片等高、图标统一套一个带主色淡底的圆角小托盘（**1.0.5 起**），标题与副标题各占一行。

在「外观 → 新对话入口」里可增删、排序、启停并自定义图标，**最多 6 个**：

- 支持三种动作：打开终端、打开 Git、把提示词填入输入框。
- 图标支持矢量图标、文字或图片。
- 删除单个入口、恢复预设均会二次确认；恢复预设会重建默认的四个入口并删除新增或修改过的入口。

## 自定义背景图

可以设置一张全局背景图：

- **选择图片**：从系统相册选一张作为 App 全局背景，叠在所有页面内容上（水印效果，不拦截触摸）。终端页保持纯黑底，不显示背景。
- **显示方式**（**1.0.3 起**）：铺满裁切（默认，裁掉边缘填满屏）、完整显示（整张可见、可能留边）、底部立绘（图片贴底部，顶部内容区保持干净）。
- **立绘高度**（仅「底部立绘」时生效，**1.0.3 起**）：立绘占屏幕比例，20% 到 80%，默认 45%。
- **蒙版强度**：滑块显示 0% 到 100%，实际生效范围映射到 0% 到 85%（即滑到 100% 相当于 85% 不透明度），以保证文字始终可读。默认 35%，拖动实时生效。
- **移除背景**：恢复默认纯色背景。

背景图文件保存在应用私有目录，**不随备份导出**，更换设备需要重新设置。

## 主题包

「外观 → 主题包」（**1.0.3 起**）把整套外观设置打包导出，或从文件导入一键套用：

- **导出主题包**：把当前外观设置打包为 JSON，可分享或备份。
- **导入主题包**：从文件读取 JSON 并一键套用，套用失败会提示「主题包可能无效」。

覆盖明暗模式、配色方案、莫奈取色、彩色图标、双侧气泡样式、四档字号、界面密度、代码显示、双侧气泡透明度、聊天面板透明系数；**不含自定义背景图**（背景图单独走备份）。

## 语言

可以跟随系统语言，也可以直接指定一种已支持的语言。

## 终端外观

终端的配色主题、字体、字号、光标样式是单独一套设置，见[终端](https://aivapp.cn/md/guide/terminal.md#外观设置)。

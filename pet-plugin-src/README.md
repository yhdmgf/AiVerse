# 桌面宠物（Desktop Pet）

AiVerse 桌面宠物插件。在桌面上以悬浮窗形式显示一只可拖拽的小宠物，它会随 AI 的运行状态实时变化，空闲时还会自己做小动作。

## 简介

插件支持三种形态——**Deepy 鲸**、**鲸娘**、**大肥鱼**。宠物以悬浮窗常驻桌面，可任意拖拽移动；状态随 AI 运行自动切换（敲代码中 / 等待确认 / 完成 / 出错）；空闲时会自动做出表情动作；长按可打开功能菜单，进行喂食、休息等互动。

## 功能列表

- **三形态切换**：Deepy 鲸 / 鲸娘 / 大肥鱼，随时在配置页或菜单里切换。
- **大小调节**：调整宠物悬浮窗的显示尺寸。
- **显示时机**：可设为「始终显示」「仅前台显示」「仅后台显示」。
- **随 App 启动**：开启后随 AiVerse 启动自动唤出宠物。
- **点击表情频率**：设置点击宠物触发表情的节流间隔（1~10 秒）。
- **自动表情**：空闲时自动做短动作，可开关，间隔可调。
- **30 秒孤独动作**：超过 30 秒无人互动，宠物会演出孤单的小动作。
- **拖拽移动**：按住宠物可拖拽到屏幕任意位置。

## 安装

1. 在 AiVerse 的「插件管理」中导入插件 zip 包。
2. 安装后请**授予悬浮窗权限**，并允许应用「显示在其他应用上层」，否则宠物无法显示在桌面上。
3. 启用插件后即可在桌面看到宠物，长按打开菜单进行形态切换与设置。
